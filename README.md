<h1 style="text-align: center">
 🪫 Battery Monitor 
</h1>

<p>
Lightweight and simple C# tray application for notifying the user when the charge reaches 80% on old/cheap laptops that don't have battery limiting features.
</p>
<br>
<img width="407" height="330" alt="VTauhXYpZs" src="https://github.com/user-attachments/assets/b19ea034-7d31-4063-9fe3-f97a1a78e99f" />

<p>Windows already does have a built-in function to notify the user when discharging to 20% or lower, but the feature cannot be re-used nor called using code for security reasons. </p>

<b>Finally stable!</b> Download [here](https://github.com/AssegaiDevelopments/Battery-Monitor/releases/tag/release).
