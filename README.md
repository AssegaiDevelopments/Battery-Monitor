<h1 style="text-align: center">
 🪫 Battery Monitor 
</h1>

<p>
Lightweight and simple C# tray application for notifying the user when the charge reaches 80% on old/cheap laptops that don't have battery limiting features.
  
Windows does already have a built-in function to notify the user when discharging to 20% or lower, but the feature cannot be re-used nor called using code for security reasons.

  <b>*currently on testing</b>
